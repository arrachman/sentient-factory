# Senti.id

Senti.id adalah website holding dan pusat ekosistem produk Senti. Website ini menjadi pintu utama yang memperkenalkan serta menghubungkan berbagai produk vertikal di bawah brand Senti.

Produk dalam ekosistem Senti antara lain:

- **Senti Klinik** — solusi untuk kebutuhan operasional dan layanan klinik.
- **Senti Edu** — solusi untuk institusi dan layanan pendidikan.
- **Senti Hotel** — solusi untuk operasional dan layanan perhotelan.
- **Senti Biz** — sistem ERP terintegrasi untuk mengelola Kas & Bank, Pembelian, dan Penjualan.

Saat mengembangkan website ini, posisikan Senti.id sebagai induk ekosistem, bukan sebagai landing page untuk satu produk saja. Struktur navigasi, konten, dan ajakan bertindak harus membantu pengunjung menemukan produk Senti yang sesuai dengan kebutuhan mereka.
