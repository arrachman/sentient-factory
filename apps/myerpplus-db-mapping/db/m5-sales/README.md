# M5 Sales Artefacts

Folder ini mengumpulkan artefak utama domain `M5 - sales` agar tidak tersebar di beberapa lokasi.

## Artefak yang Dikumpulkan

- `m0_report_rmoduleid_5.sql`
- `m5-queries.md`
- `m5-queries-by-type.md`
- `semantic-schema-m5.json`
- `semantic-schema-sales.json`
- `semantic-schema-m5-summary.md`
- `semantic-schema-m5-nl2sql.md`
- `semantic-schema-m5-nl2sql.json`

## Catatan

- `semantic-schema-m5-summary-flat.json` diminta sebagai bagian dari kumpulan ini, tetapi file tersebut belum tersedia di workspace saat folder ini dibuat.
- `semantic-schema-m5.json` adalah source of truth domain M5.
- `semantic-schema-sales.json` adalah schema gabungan area sales.
- `semantic-schema-m5-summary.md` adalah ringkasan manusia-readable.
- `semantic-schema-m5-nl2sql.md` dan `semantic-schema-m5-nl2sql.json` adalah guide operasional untuk NL2SQL.
