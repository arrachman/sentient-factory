F0010: Role CRUD Operations

Overview​

Complete CRUD operations untuk role management dengan permission assignment.

Technical Context​

  • Location: apps/web-dashboard/app/roles/[id]/
  • Components: Role form, permission selector, user reassignment modal
  • Technologies: React Hook Form, Zod, Tree visualization, Real-time validation
  • API Integration: POST /api/roles, PUT /api/roles/{id}, DELETE /api/roles/{id}

User Story​

As an administrator
I want to create, edit, and delete roles with specific permissions
So that I can define exactly what each role can access in the system

Acceptance Criteria​

Functional Requirements​

  1. AC1: Create role form dengan fields: Name, Description, Parent Role
  2. AC2: Permission selection interface dengan module grouping
  3. AC3: Edit role mempertahankan existing permissions
  4. AC4: Delete role dengan user reassignment options
  5. AC5: Clone role menghasilkan duplicate dengan semua permissions
  6. AC6: Permission inheritance dari parent roles bekerja
  7. AC7: Real-time permission summary saat selection berubah
  8. AC8: Role validation (unique names, valid permissions)

Technical Requirements​

  1. TR1: Role templates untuk common role types
  2. TR2: Bitmask permissions untuk performance
  3. TR3: Permission caching mechanism
  4. TR4: Optimistic updates untuk better UX
  5. TR5: Form dirty state tracking
  6. TR6: Conflict detection untuk permission combinations
  7. TR7: Real-time collaboration indicators
  8. TR8: Offline capability dengan sync

Service Layer​

// CRUD Service
interface RoleCrudService {
  createRole(data: CreateRoleData): Promise<Role>;
  getRole(id: string): Promise<RoleDetail>;
  updateRole(id: string, data: UpdateRoleData): Promise<Role>;
  deleteRole(id: string, reassignment?: ReassignmentOptions): Promise<void>;
  cloneRole(id: string, options: CloneOptions): Promise<Role>;
}

// Permission Calculator
interface PermissionCalculator {
  calculateInheritedPermissions(roleId: string): Promise<PermissionSet>;
  validatePermissionCombinations(
    permissions: string[],
  ): Promise<ValidationResult>;
  getPermissionConflicts(roleId: string): Promise<PermissionConflict[]>;
  optimizePermissionBits(permissions: string[]): Promise<number>;
}

// Template Service
interface TemplateService {
  getRoleTemplates(): Promise<RoleTemplate[]>;
  applyTemplate(templateId: string, roleData: Partial<Role>): Promise<Role>;
  saveAsTemplate(roleId: string, templateName: string): Promise<void>;
  deleteTemplate(templateId: string): Promise<void>;
}

Form Validation Schemas​

const roleSchema = z.object({
  name: z
    .string()
    .min(3, "Minimum 3 characters")
    .max(50, "Maximum 50 characters")
    .regex(
      /^[a-zA-Z0-9\s\-_]+$/,
      "Only letters, numbers, spaces, hyphens, and underscores",
    ),
  description: z
    .string()
    .min(10, "Minimum 10 characters")
    .max(500, "Maximum 500 characters"),
  parentRoleId: z.string().optional(),
  isDefault: z.boolean().optional(),
  permissions: z.array(z.string()).min(1, "At least one permission required"),
});

const deleteRoleSchema = z.object({
  reassignmentRoleId: z.string().optional(),
  deleteAssignedUsers: z.boolean().optional(),
  deleteOrphanedPermissions: z.boolean().optional(),
  confirmation: z.string().refine((val) => val === "DELETE ROLE", {
    message: "Must type 'DELETE ROLE' to confirm",
  }),
});

interface RoleCrudState {

Security Considerations​

Role Management Security​

  1. Authorization Checks:

    • Verify user has role CRUD permissions
    • Prevent modification of system-critical roles
    • Validate permission assignments

  2. Data Validation:

    • Input sanitization untuk role names
    • Permission existence validation
    • Hierarchy cycle prevention
    • Default role protection

  3. Audit Trail:

    • Log semua role CRUD operations
    • Track permission changes
    • Record inheritance modifications
    • Export operation history

Permission Security​

  1. Permission Validation:

    • Verify permission existence sebelum assignment
    • Check permission compatibility
    • Prevent conflicting permission assignments
    • Validate inheritance chains

  2. Access Control:

    • Role-based access untuk permission management
    • Granular permission checks
    • Real-time permission validation
    • Offline permission caching

Performance Requirements​

Operation Performance​

  • Role Load Time: < 1 second
  • Permission Calculation: < 500ms
  • Form Submission: < 2 seconds
  • Delete with Reassignment: < 5 seconds (per user)

Optimizations​

  1. Permission Optimization:

    • Bitmask permissions untuk fast calculations
    • Permission caching mechanism
    • Lazy loading untuk permission lists
    • Optimized inheritance algorithms

  2. Form Optimization:

    • Debounced validation

    • Form state persistence
    • Progressive loading untuk large permission sets
