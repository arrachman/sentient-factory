F0006: Edit User Functionality

Overview​

Form untuk mengedit user profile, change password, dan update role assignments.

Technical Context​

  • Location: apps/web-dashboard/app/users/[id]/edit/
  • Components: Edit user modal, form components, profile picture upload
  • Technologies: React Hook Form, Zod, File upload, Image processing
  • API Integration: GET /api/users/{id}, PUT /api/users/{id}

User Story​

As an administrator
I want to edit user profiles and update their permissions
So that I can keep user information current and adjust access as needed

Acceptance Criteria​

Functional Requirements​

  1. AC1: Edit modal terbuka dengan pre-filled user data
  2. AC2: Form sections: Personal Info, Security, Roles & Permissions
  3. AC3: Change password functionality memvalidasi old password
  4. AC4: Role updates langsung ter-reflect di system
  5. AC5: Profile picture upload dengan preview dan crop functionality
  6. AC6: Two-factor authentication dapat di-enable/disable
  7. AC7: Audit log mencatat semua profile changes
  8. AC8: Changes disimpan dengan confirmation feedback

Technical Requirements​

  1. TR1: Form validation menggunakan Zod schema
  2. TR2: Optimistic updates untuk better UX
  3. TR3: Form dirty state tracking
  4. TR4: Image compression untuk uploaded pictures
  5. TR5: Secure password change dengan old password validation
  6. TR6: Real-time permission summary display
  7. TR7: Responsive design untuk mobile
  8. TR8: Keyboard navigation support

Form Validation Schemas​

const personalInfoSchema = z.object({
  firstName: z.string().min(2, "Minimum 2 characters").max(50),
  lastName: z.string().min(2, "Minimum 2 characters").max(50),
  email: z.string().email("Invalid email address"),
  phone: z.string().optional(),
  department: z.string().optional(),
  position: z.string().optional(),
});

const changePasswordSchema = z
  .object({
    oldPassword: z.string().min(8, "Minimum 8 characters"),
    newPassword: z
      .string()
      .min(8, "Minimum 8 characters")
      .regex(/[A-Z]/, "Must contain uppercase letter")
      .regex(/[a-z]/, "Must contain lowercase letter")
      .regex(/[0-9]/, "Must contain number")
      .regex(/[^A-Za-z0-9]/, "Must contain special character"),
    confirmPassword: z.string(),
  })
  .refine((data) => data.newPassword === data.confirmPassword, {
    message: "Passwords don't match",
    path: ["confirmPassword"],
  });

Security Considerations​

Authentication & Authorization​

  1. User Authorization:

    • Verify user has permission to edit other users
    • Role-based access control untuk sensitive fields
    • Prevent self-demotion jika user is admin

  2. Password Security:

    • Old password required untuk change
    • Strong password requirements
    • Password not logged atau stored in plain text

  3. Data Validation:

    • Server-side validation untuk all updates
    • SQL injection prevention
    • XSS protection untuk user inputs

File Upload Security​

  1. File Validation:

    • File type verification (images only)
    • File size limits (max 5MB)
    • Malware scanning untuk uploaded files

  2. Storage Security:

    • Secure file storage dengan access controls
    • CDN dengan proper caching headers
    • File access authentication

Performance Requirements​

Load Time​

  • Form Load Time: < 1 second
  • Image Upload Processing: < 3 seconds
  • Form Submission: < 2 seconds
  • Initial Page Load: < 1.5 seconds

Optimizations​

  1. Lazy Loading:

    • Lazy load image processing library
    • Code splitting untuk form sections
    • Dynamic imports untuk heavy components

  2. Caching:

    • User data caching untuk faster reloads
    • Image CDN caching
    • Form state persistence

Accessibility Requirements​

WCAG 2.1 AA Compliance​

  1. Keyboard Navigation:

    • Tab through all form elements
    • Keyboard shortcuts untuk tab switching
    • Escape to close modal

  2. Screen Reader Support:

    • ARIA labels untuk all form fields
    • Form error announcements
    • Loading state announcements

  3. Visual Accessibility:

    • Sufficient color contrast (4.5:1 minimum)
    • Focus indicators untuk all interactive elements
    • Responsive design untuk all screen sizes

Error Handling​

Expected Errors​

  1. Validation Errors:

    • Invalid email format
    • Weak password
    • Incorrect old password
    • File too large

  2. Network Errors:

    • API timeout
    • Server errors
    • Network disconnection

  3. Permission Errors:

    • Insufficient permissions to edit user
    • Cannot edit own admin role
    • Role assignment conflicts

Recovery Strategies​

  1. Form Recovery:

    • Auto-save draft functionality
    • Session storage untuk form data
    • Recovery after page refresh

  2. Network Recovery:

    • Automatic retry untuk failed requests
    • Offline mode dengan queued updates
    • Clear error messages dengan retry options
