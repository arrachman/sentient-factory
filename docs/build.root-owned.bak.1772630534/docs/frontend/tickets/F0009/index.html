F0009: Roles List Page

Overview​

Halaman untuk menampilkan, mengelola, dan mengatur roles dalam sistem.

Technical Context​

  • Location: apps/web-dashboard/app/roles/
  • Components: Roles table, role hierarchy visualization, statistics dashboard
  • Technologies: React, DataTable, Tree visualization, Chart.js
  • API Integration: GET /api/roles, GET /api/roles/statistics

User Story​

As an administrator
I want to view and manage all system roles
So that I can control access permissions and role hierarchies

Acceptance Criteria​

Functional Requirements​

  1. AC1: Table menampilkan roles dengan columns: Name, Description, User Count, Permissions
  2. AC2: Create, edit, delete buttons tersedia untuk role management
  3. AC3: Role hierarchy visualization menunjukkan parent-child relationships
  4. AC4: Default role assignment configuration
  5. AC5: Search dan filter berdasarkan role name atau description
  6. AC6: Role statistics (total roles, default roles, custom roles)
  7. AC7: Clone role functionality untuk duplicate existing roles
  8. AC8: Export roles list to JSON/CSV

Technical Requirements​

  1. TR1: Role dependency checking
  2. TR2: Role usage analytics
  3. TR3: Real-time role updates
  4. TR4: Bulk role operations
  5. TR5: Responsive table design
  6. TR6: Keyboard navigation support
  7. TR7: Role validation (unique names)
  8. TR8: Performance optimization untuk large role sets

Service Layer​

// Role Service
interface RoleService {
  getRoles(filters: RoleFilters): Promise<Role[]>;
  getRoleStats(): Promise<RoleStats>;
  createRole(role: CreateRoleData): Promise<Role>;
  updateRole(id: string, role: UpdateRoleData): Promise<Role>;
  deleteRole(id: string): Promise<void>;
  cloneRole(id: string, newName: string): Promise<Role>;
  exportRoles(format: "csv" | "json"): Promise<Blob>;
}

// Hierarchy Service
interface HierarchyService {
  getRoleHierarchy(): Promise<RoleHierarchy>;
  updateHierarchy(hierarchy: HierarchyUpdate): Promise<void>;
  validateHierarchy(hierarchy: RoleHierarchy): Promise<ValidationResult>;
  getHierarchyConflicts(): Promise<HierarchyConflict[]>;
}

// Statistics Service
interface StatisticsService {
  getRoleUsageStats(): Promise<RoleUsageStats>;
  getPermissionDistribution(): Promise<PermissionDistribution>;
  getRoleGrowthTrend(days: number): Promise<GrowthTrend>;
  getRoleAssignmentStats(): Promise<AssignmentStats>;
}

State Management​

interface RolesState {
  roles: Role[];
  hierarchy: RoleHierarchy;
  stats: RoleStats;
  filters: RoleFilters;
  selectedRoles: string[];
  isLoading: boolean;
  setFilters: (filters: RoleFilters) => void;
  selectRole: (id: string) => void;
  selectAllRoles: () => void;
  clearSelection: () => void;
  applyBulkAction: (action: BulkAction) => Promise<void>;
  refreshData: () => Promise<void>;
}

Security Considerations​

Role Management Security​

  1. Permission Checks:

    • Verify user has role management permissions
    • Prevent deletion of system-critical roles
    • Validate role hierarchy changes

  2. Data Validation:

    • Unique role name validation
    • Permission existence validation
    • Hierarchy cycle detection
    • Default role protection

  3. Audit Trail:

    • Log semua role management operations
    • Track who created/modified/deleted roles
    • Record hierarchy changes
    • Export operation logging

Export Security​

  1. Data Protection:

    • Sensitive data masking dalam exports
    • Role permission details protection
    • Export file access control
    • Automatic expiration untuk export files

  2. Access Control:

    • Export permission requirements
    • Rate limiting untuk exports
    • File download tracking
    • Suspicious export detection

Performance Requirements​

Page Load Performance​

  • Initial Page Load: < 2 seconds
  • Table Rendering (100 roles): < 1 second
  • Hierarchy Rendering: < 1.5 seconds
  • Statistics Calculation: < 1 second

Optimizations​

  1. Data Loading:

    • Lazy loading untuk hierarchy visualization
    • Paginated API calls untuk roles data
    • Caching untuk statistics data
    • Progressive loading untuk large datasets

  2. Rendering Optimization:

    • Virtual scrolling untuk roles table
    • Memoized components untuk performance
    • Debounced search inputs
    • Optimized tree rendering

Accessibility Requirements​

WCAG 2.1 AA Compliance​

  1. Keyboard Navigation:

    • Tab through all interactive elements
    • Keyboard shortcuts untuk common actions
    • Escape to close modals
    • Arrow keys untuk hierarchy navigation

  2. Screen Reader Support:

    • ARIA labels untuk all table elements

  3. Visual Accessibility:

    • High contrast mode support
    • Color-blind friendly visualizations
    • Responsive design untuk all screen sizes
    • Zoom compatibility

Error Handling​

Expected Errors​

  1. Validation Errors:

    • Duplicate role name
    • Invalid permission references
    • Hierarchy cycle creation
    • Missing required fields

  2. Network Errors:

    • API timeout during role operations
    • Export generation failures
    • Statistics calculation failures
    • Hierarchy update conflicts

  3. Permission Errors:

    • Insufficient permissions untuk role management
    • Cannot delete assigned roles
    • Cannot modify system roles

Recovery Strategies​

  1. Operation Recovery:

    • Undo functionality untuk role changes
    • Conflict resolution untuk hierarchy updates
    • Retry mechanism untuk failed operations
    • Draft saving untuk form data

  2. Data Recovery:

    • Role backup system
    • Hierarchy version control
    • Export-based recovery
    • Emergency restore procedures
