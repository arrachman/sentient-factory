Brand Guidelines

Overview​

Sentient Factory is an intelligent manufacturing platform that transforms traditional factories into smart, AI-powered production facilities. Our brand represents innovation, reliability, and intelligence in industrial automation.

Brand Identity​

Brand Name​

Sentient Factory

Tagline: Intelligent Manufacturing, Powered by AI

Pronunciation: SEN-tee-ent FAK-tuh-ree

Brand Story​

Sentient Factory was founded on the principle that manufacturing should be intelligent, predictive, and efficient. We combine cutting-edge AI with industrial expertise to create factories that can think, learn, and optimize themselves in real-time.

Core Values​

  1. Intelligence: Leveraging AI to make manufacturing smarter
  2. Reliability: Building systems that industries can depend on
  3. Innovation: Continuously pushing the boundaries of what's possible
  4. Partnership: Working closely with manufacturers to solve real problems
  5. Sustainability: Optimizing resources for a greener future

Visual Identity​

Logo​

The Sentient Factory logo combines industrial precision with digital intelligence.

Primary Logo

[SF]

Full Logo

Sentient Factory
Intelligent Manufacturing

Logo Usage Guidelines:

  • Minimum clear space: 20% of logo height on all sides
  • Minimum size: 24px digital, 0.5" print
  • Never stretch or distort the logo
  • Use only approved color variations

Color Palette​

Primary Colors​

  • Factory Blue: #0066CC (RGB: 0, 102, 204)
    • Usage: Primary brand color, buttons, highlights
  • Industrial Gray: #333333 (RGB: 51, 51, 51)
    • Usage: Text, backgrounds, UI elements

Secondary Colors​

  • AI Teal: #00CCCC (RGB: 0, 204, 204)
    • Usage: AI features, data visualization
  • Success Green: #00CC66 (RGB: 0, 204, 102)
    • Usage: Success states, positive metrics
  • Alert Orange: #FF9900 (RGB: 255, 153, 0)
    • Usage: Warnings, attention needed
  • Error Red: #FF3333 (RGB: 255, 51, 51)
    • Usage: Errors, critical alerts

Neutral Colors​

  • Light Gray: #F5F5F5 (RGB: 245, 245, 245)
  • Medium Gray: #CCCCCC (RGB: 204, 204, 204)
  • Dark Gray: #666666 (RGB: 102, 102, 102)

Typography​

Primary Font: Inter​

  • Weights: Regular (400), Medium (500), SemiBold (600), Bold (700)
  • Usage: Headlines, body text, UI elements
  • Fallback: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif

Secondary Font: Roboto Mono​

  • Weights: Regular (400), Medium (500)
  • Usage: Code snippets, technical data, metrics
  • Fallback: 'Courier New', Courier, monospace

Font Sizes​

Iconography​

Style Guidelines​

  • Line weight: 2px
  • Corners: Slightly rounded (2px radius)
  • Style: Modern, clean, technical
  • Consistency: Maintain consistent visual weight

Icon Categories​

  1. Navigation: Dashboard, Analytics, Settings
  2. Factory: Production lines, Sensors, Equipment
  3. AI: Brain, Neural network, Prediction
  4. Data: Charts, Graphs, Metrics
  5. Alerts: Notifications, Warnings, Errors

Photography & Imagery​

Style​

  • Clean, professional, well-lit
  • Show real manufacturing environments
  • Highlight technology integration
  • People interacting with systems
  • Data visualization examples

Do's and Don'ts​

  • Do: Use high-quality, relevant images
  • Do: Show diversity in manufacturing settings
  • Do: Include people using the platform
  • Don't: Use generic stock photos
  • Don't: Show outdated equipment
  • Don't: Use blurry or low-resolution images

Compliance & Legal​

  • Privacy policy on all marketing materials

Content Usage​

  • Obtain proper licenses for all images
