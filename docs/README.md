# Sentient Factory — Portal Dokumentasi

Docusaurus **multi-instance** yang melayani dokumentasi untuk tiga produk Senti
dalam satu situs: **HR**, **ERP**, **MDP** — plus dokumentasi internal/dev.

- Dev: `npm run docs:dev` (root) atau `npm run start` (di `docs/`) → port **3205**.
- Build: `npm run docs:build` (root) atau `npm run build` (di `docs/`).
- Serve hasil build: `cd docs && npm run serve -- --port 3205`.

## Struktur

```
docs/
├── config/products.ts        # SSOT daftar produk (dipakai config + portal)
├── docusaurus.config.ts      # 3 instance plugin-content-docs + preset internal
├── sidebars.ts               # sidebar docs internal (/internal)
├── sidebars-hr|erp|mdp.ts    # sidebar autogenerated per produk
├── docs/                     # konten internal/dev → route /internal
├── hr/  erp/  mdp/           # konten produk → route /hr /erp /mdp
├── i18n/id/                  # scaffold terjemahan (default locale: id)
└── src/pages/index.tsx       # portal landing (3 kartu produk)
```

Rute: `/` (portal) · `/hr` · `/erp` · `/mdp` · `/internal` · `/blog`.

## Menambah produk baru

Tambah satu entry di `config/products.ts` → plugin docs, link navbar, dan kartu
portal otomatis ikut. Buat folder `<id>/` + `sidebars-<id>.ts`.

## Versioning (per produk)

Versioning Docusaurus aktif per instance. Cut snapshot saat rilis:

```bash
cd docs
npm run version:hr  -- 1.0     # → versioned_docs/version-1.0 untuk HR
npm run version:erp -- 1.0
npm run version:mdp -- 1.0
```

Setelah versi pertama di-cut, tambahkan selektor versi di navbar
(`docusaurus.config.ts`): item `{ type: "docsVersionDropdown", docsPluginId: "<id>", position: "right" }`.

## i18n

Default locale **`id`** (Bahasa Indonesia), `en` disiapkan tapi belum diisi.
Regenerate string UI: `npm run write-translations -- --locale id`.
Build satu locale: `npm run build -- --locale id`.

## Keputusan arsitektur (terkunci 2026-06-30, dengan user)

| # | Keputusan | Alasan |
| --- | --- | --- |
| D1 | Tetap di root `docs/` (bukan `apps/docs/`) | Instance sudah ada, sudah di-proxy & punya script; pindah = mahal tanpa manfaat |
| D2 | Multi-instance dalam **satu** situs (bukan 3 app terpisah) | 1 port/UFW, 1 theme, 1 search, cross-link antar produk mudah; HR/ERP/MDP satu suite |
| D3 | Default locale `id`, locale `en` disiapkan | Audiens end-user/operator lokal |
| D4 | Routing `/hr` `/erp` `/mdp`, internal di `/internal` | Pemisahan bersih; homepage = portal |
| D5 | Versioning aktif per produk | Rilis HR ≠ ERP ≠ MDP |
| D6 | Domain publik `docs.fr-labs.my.id` (subdomain) | Lebih bersih dari path `/docs`; port dev 3205 tetap loopback di balik proxy |

Audiens dokumentasi = **end-user/operator + admin/implementator** → konten
task-oriented (Panduan Pengguna + Panduan Admin per produk), bukan API/arsitektur.

## Langkah manual (di luar kemampuan agent — perlu kamu jalankan)

1. **UFW** (akses dev LAN, opsional karena produksi via proxy):
   ```bash
   sudo ufw allow from 192.168.1.0/24 to any port 3205 proto tcp comment 'docs docusaurus'
   sudo ufw reload
   ```
2. **DNS**: tambah A-record `docs.fr-labs.my.id` → IP host.
3. **nginx**: aktifkan vhost `infra/nginx/docs.fr-labs.my.id.conf` (symlink ke
   `sites-enabled` / muat ke container proxy), lalu `nginx -t && reload`.
4. **TLS**: terbitkan sertifikat (certbot) lalu tambah blok `listen 443`.
5. **Jalankan**: `npm run docs:build` lalu jalankan `docusaurus serve` di 3205
   (via pm2/systemd) agar proxy punya upstream.

## Catatan kebersihan

Build lama milik `root` tersisa sebagai `docs/.docusaurus.old-root-*` dan
`docs/build.old-root-*` (di-`.gitignore`). Hapus manual: `sudo rm -rf docs/*.old-root-*`.
