# Senti MDP

**Senti MDP** (*Manufacturing Digitalization Platform*) adalah sistem
ISA-95 **Level 3 / MOM** yang menjembatani Senti ERP (Level 4) dengan
operasi di lapangan (Level 2–0).

Dokumentasi ini ditujukan untuk:

- **Pengguna / Operator** — operator produksi, QC, dan teknisi yang mencatat
  hasil kerja di lantai pabrik. → **Panduan Pengguna**.
- **Admin / Implementator** — yang menyiapkan master MOM, alur kerja, dan
  parameter OEE. → **Panduan Admin**.

## Modul utama

| Modul | Domain | Fungsi |
| --- | --- | --- |
| MES | mes | Eksekusi & pelaporan produksi |
| QMS | qms | Inspeksi & kontrol kualitas |
| CMMS | mnt | Pemeliharaan aset/mesin |
| WMS | wms | Operasi gudang lantai produksi |
| PRTS | prt | Penelusuran part/komponen |
| DMS | dms | Manajemen dokumen lantai |
| IMS | ehs | QHSE / keselamatan |
| LMS | lms | Kompetensi & pelatihan |
| OEE | (overlay) | Overall Equipment Effectiveness (turunan) |
