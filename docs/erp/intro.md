# Senti ERP

**Senti ERP** adalah sistem *Enterprise Resource Planning* untuk mengelola
master data, keuangan, pembelian, dan persediaan dalam satu platform.

Dokumentasi ini ditujukan untuk:

- **Pengguna / Operator** — yang membuat transaksi harian (faktur, PO,
  penerimaan barang). → **Panduan Pengguna**.
- **Admin / Implementator** — yang menyiapkan master data, bagan akun,
  dan penomoran dokumen. → **Panduan Admin**.

## Modul utama

| Modul | Fungsi |
| --- | --- |
| Master Data | Item, partner/kontak, gudang & lokasi penyimpanan |
| Finance | Jurnal, AR/AP, kas/bank, giro, laporan keuangan |
| Purchasing | PR, PO, penerimaan barang (GRN), retur |
| Inventory | Stok, penyesuaian, mutasi antar gudang |
| Penomoran Dokumen | Format & urutan nomor dokumen per jenis |
| Laporan | Neraca, laba rugi, buku besar, faktur cetak |

:::tip Versi dokumen
Gunakan pemilih versi di bilah navigasi untuk membuka dokumentasi versi rilis
tertentu.
:::
