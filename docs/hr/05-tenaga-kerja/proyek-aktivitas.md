# Proyek & Aktivitas

Rute `/app/projects` · grup **Manajemen Tenaga Kerja** · *live* · **privileged**.

Master **proyek** dan **pencatatan waktu per proyek** — adaptasi *jibble
Projects*. Memungkinkan analisis jam kerja per proyek dan penagihan jam *billable*.

![Proyek & Aktivitas](/img/hr/proyek-aktivitas.png)

## Bagian layar

Dua tab:

### Tab **Master Proyek**

Tombol **+ Tambah Proyek** menambah proyek baru.

| Kolom | Isi |
| --- | --- |
| **Kode** | Kode proyek (mis. `PROJ-A`, `INTERNAL`). |
| **Nama** | Nama proyek. |
| **Klien** | Klien terkait (kosong untuk internal). |
| **Tipe** | `Billable` (dapat ditagih) / `Internal`. |

Ikon **edit**/**hapus** per baris.

### Tab **Catatan Waktu**

Pencatatan durasi kerja per proyek (time entry) lewat dialog waktu proyek.

## Alur

1. Pada **Master Proyek**, buat proyek dan tetapkan **tipe** (Billable/Internal).
2. Pindah ke **Catatan Waktu**, catat durasi kerja per proyek.
3. Rekap jam per proyek tersedia di
   [Laporan → Jam per Proyek](/hr/laporan-lainnya/laporan).
