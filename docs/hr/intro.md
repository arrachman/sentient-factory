# Senti HR

**Senti HR** adalah platform *Time & Attendance / Workforce Management* untuk
mencatat kehadiran, mengelola jadwal kerja, cuti, dan laporan jam kerja.

Dokumentasi ini ditujukan untuk **dua jenis pengguna**:

- **Pengguna / Operator** — karyawan & supervisor yang melakukan absensi,
  mengajukan cuti, dan menyetujui timesheet. → lihat **Panduan Pengguna**.
- **Admin / Implementator** — yang menyiapkan organisasi, lokasi, shift,
  dan kebijakan. → lihat **Panduan Admin**.

## Modul utama

| Modul | Fungsi |
| --- | --- |
| Absensi | Clock-in/out, pengenalan wajah, GPS/geofence |
| Timesheet | Rekap jam kerja harian/mingguan |
| Jadwal & Shift | Pengaturan pola kerja dan rotasi |
| Cuti | Pengajuan & approval cuti/izin |
| Project & Activity | Pelacakan waktu per proyek/aktivitas |
| Laporan | Ekspor jam kerja untuk payroll |

:::tip Versi dokumen
