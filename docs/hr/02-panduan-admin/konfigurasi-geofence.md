# Konfigurasi Lokasi & Geofence

Admin mengatur lokasi kerja dan radius geofence yang dipakai untuk memvalidasi
absensi berbasis GPS.

## Langkah

1. Masuk sebagai admin, buka **Pengaturan → Lokasi**.
2. Tekan **Tambah Lokasi**, isi nama dan titik koordinat (atau pilih di peta).
3. Tentukan **radius geofence** (meter) toleransi absensi.
4. Tetapkan karyawan/grup yang terikat pada lokasi tersebut.
5. Simpan. Perubahan berlaku untuk absensi berikutnya.

## Praktik baik

- Sesuaikan radius dengan akurasi GPS perangkat (umumnya 50–150 m).
- Tinjau laporan *out of range* berkala untuk menyetel radius.
