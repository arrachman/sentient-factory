# B0011: Testing & Documentation

## Description

Ensure code quality and API discoverability.

## Acceptance Criteria

- [ ] **Swagger:** Setup `@nestjs/swagger` at `/api/docs`.
- [ ] Document all DTOs and Endpoints with `@ApiProperty`, `@ApiOperation`.
- [ ] **Unit Tests:** Write `.spec.ts` for Services.
- [ ] **E2E Tests:** Write integration tests for critical flows (Auth, User CRUD).

## Technical Details

- Swagger UI accessible in dev mode.
- Jest for testing framework.
