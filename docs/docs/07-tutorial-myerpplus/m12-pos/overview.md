# m12-pos

The `m12-pos` module covers the POS or retail transaction flow, including POS setup, promo, voucher, loyalty, and cashier sales transactions.

- POS master setup
- promo and loyalty
- voucher and payment relations
- POS sales transactions
- configuration and document history
