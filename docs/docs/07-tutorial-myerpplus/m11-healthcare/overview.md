# m11-healthcare

This category contains tutorials for the healthcare or clinic domain in MyERPPlus.

## Coverage

- patient visits
- service billing and payments
- clinical services, lab, prescriptions, and medical records

## Main Documents

- [M11 Query Artifacts](./query-artifacts.md)
- [M11 Schema and AI SQL Artifacts](./schema-and-ai-sql-artifacts.md)

## Notes

The active M11 source uses the `m_11_*` table prefix. Artifacts in this category are built from active queries and reports so the healthcare domain can be used for retrieval and readonly NL2SQL.
