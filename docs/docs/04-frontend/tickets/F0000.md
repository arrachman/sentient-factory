# F0000: Admin UI Scaffolding (Static)

## **Overview**

Implementasi awal struktur visual aplikasi web-dashboard. Tiket ini fokus pada pembuatan **Halaman Login**, **Layout Dashboard**, dan **Sidebar Menu** khusus untuk role **Administrator** secara statis (tanpa integrasi API backend). Tujuannya adalah untuk memvalidasi desain UI/UX sebelum masuk ke pengembangan logika fungsional.

## **Technical Context**

- **Location**: `apps/web-dashboard/app/`
- **Components**: `LoginLayout`, `DashboardLayout`, `Sidebar`, `Header`
- **Technologies**: Next.js 14, Tailwind CSS, shadcn/ui (atau Metronic components), Lucide Icons
- **Mock Data**: Hardcoded user data & navigation items

## **User Story**

**As an** Administrator
**I want to** see the login page and navigate the dashboard sidebar
**So that** I can verify the look and feel of the administration panel structure

## **Acceptance Criteria**

### **Functional Requirements (UI Only)**

1. **AC1**: Halaman Login dapat diakses di `/auth/login` dengan tampilan visual sesuai desain.
2. **AC2**: Tombol "Login" pada form mengarahkan user ke `/admin/dashboard` (mock redirection).
3. **AC3**: Halaman Dashboard memiliki layout standar: Sidebar (kiri), Header (atas), dan Content Area (tengah).
4. **AC4**: Sidebar menampilkan menu khusus Administrator: "Dashboard", "User Management", "Settings".
5. **AC5**: Header menampilkan user avatar statis dan tombol Logout.
6. **AC6**: Tombol "Logout" mengarahkan kembali ke halaman login.
7. **AC7**: Tampilan responsif pada mobile (sidebar bisa di-collapse/toggle).

### **Technical Requirements**

1. **TR1**: Menggunakan Next.js App Router layout (`layout.tsx`).
2. **TR2**: Tidak ada pemanggilan API (`fetch` / `axios`).
3. **TR3**: Menggunakan mock data untuk list menu sidebar.
4. **TR4**: Component terpisah untuk `Sidebar`, `Header`, dan `Footer`.
