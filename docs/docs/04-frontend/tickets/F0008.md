# F0008: User Profile Management Page

## **Overview**

Dedicated page untuk user profile management dengan personal info, security settings, dan activity history.

## **Technical Context**

- **Location**: `apps/web-dashboard/app/profile/`
- **Components**: Profile page, settings sections, activity history, connected devices
- **Technologies**: Next.js 14, React Hook Form, Zod, WebSocket (for active sessions)
- **API Integration**: GET/PUT `/api/profile`, GET `/api/activity`, GET `/api/sessions`

## **User Story**

**As a** system user  
**I want to** view and manage my own profile settings  
**So that** I can keep my information updated and secure my account

## **Acceptance Criteria**

### **Functional Requirements**

1. **AC1**: Profile page accessible via user dropdown menu
2. **AC2**: Page sections: Personal Info, Security, Preferences, Activity
3. **AC3**: Personal info section dapat di-edit dan disimpan
4. **AC4**: Security section memiliki change password dan 2FA setup
5. **AC5**: Preferences section untuk language, timezone, notifications
6. **AC6**: Activity history menampilkan login history dan actions
7. **AC7**: Connected devices section menampilkan active sessions
8. **AC8**: Responsive design untuk semua screen sizes

### **Technical Requirements**

1. **TR1**: Profile completion progress indicator
2. **TR2**: Dark mode preference toggle
3. **TR3**: Email verification flow
4. **TR4**: Session management dengan force logout capability
5. **TR5**: Activity pagination dan filtering
6. **TR6**: Real-time updates untuk active sessions
7. **TR7**: Form auto-save functionality
8. **TR8**: Mobile-responsive design dengan touch optimization

### **Service Layer**

```typescript
// Profile Service
interface ProfileService {
  getProfile(): Promise<UserProfile>;
  updateProfile(data: Partial<UserProfile>): Promise<UserProfile>;
  changePassword(oldPassword: string, newPassword: string): Promise<void>;
  setupTwoFactor(): Promise<TwoFactorSetup>;
  verifyTwoFactor(code: string): Promise<void>;
  disableTwoFactor(): Promise<void>;
}

// Activity Service
interface ActivityService {
  getActivities(filters: ActivityFilters): Promise<Activity[]>;
  getActivityStats(): Promise<ActivityStats>;
  exportActivities(format: "csv" | "json"): Promise<Blob>;
}

// Session Service
interface SessionService {
  getActiveSessions(): Promise<Session[]>;
  terminateSession(sessionId: string): Promise<void>;
  terminateAllOtherSessions(): Promise<void>;
  getSessionGeoInfo(sessionId: string): Promise<GeoInfo>;
}
```

### **Form Validation Schemas**

```typescript
const personalInfoSchema = z.object({
  firstName: z.string().min(2, "Minimum 2 characters").max(50),
  lastName: z.string().min(2, "Minimum 2 characters").max(50),
  email: z.string().email("Invalid email address"),
  phone: z.string().optional(),
  avatar: z.string().url("Invalid URL").optional(),
  bio: z.string().max(500, "Maximum 500 characters").optional(),
});

const preferencesSchema = z.object({
  language: z.enum(["en", "id", "ja", "ko"]),
  timezone: z.string(),
  theme: z.enum(["light", "dark", "auto"]),
  emailNotifications: z.boolean(),
  pushNotifications: z.boolean(),
  weeklyDigest: z.boolean(),
});
```

## **Security Considerations**

### **Authentication & Authorization**

1. **Profile Access Control**:
   - Users can only access own profile
   - Session validation untuk all operations
   - Rate limiting untuk sensitive actions

2. **Password Security**:
   - Strong password requirements
   - Old password verification untuk changes
   - Password not logged atau stored in plain text

3. **Two-Factor Authentication**:
   - Secure QR code generation
   - Backup codes storage
   - Recovery procedures
   - Time-based one-time password validation

### **Session Security**

1. **Session Management**:
   - Active session tracking
   - Device fingerprinting
   - Suspicious activity detection
   - Automatic session termination

2. **Data Protection**:
   - Personal data encryption
   - Secure file upload untuk avatars
   - Audit logging untuk all profile changes
   - GDPR compliance features
