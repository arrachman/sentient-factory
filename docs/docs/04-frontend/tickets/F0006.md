### **Form Validation Schemas**

```typescript
const personalInfoSchema = z.object({
  firstName: z.string().min(2, "Minimum 2 characters").max(50),
  lastName: z.string().min(2, "Minimum 2 characters").max(50),
  email: z.string().email("Invalid email address"),
  phone: z.string().optional(),
  department: z.string().optional(),
  position: z.string().optional(),
});

const changePasswordSchema = z
  .object({
    oldPassword: z.string().min(8, "Minimum 8 characters"),
    newPassword: z
      .string()
      .min(8, "Minimum 8 characters")
      .regex(/[A-Z]/, "Must contain uppercase letter")
      .regex(/[a-z]/, "Must contain lowercase letter")
      .regex(/[0-9]/, "Must contain number")
      .regex(/[^A-Za-z0-9]/, "Must contain special character"),
    confirmPassword: z.string(),
  })
  .refine((data) => data.newPassword === data.confirmPassword, {
    message: "Passwords don't match",
    path: ["confirmPassword"],
  });
```

## **Security Considerations**

### **Authentication & Authorization**

1. **User Authorization**:
   - Verify user has permission to edit other users
   - Role-based access control untuk sensitive fields
   - Prevent self-demotion jika user is admin

2. **Password Security**:
   - Old password required untuk change
   - Strong password requirements
   - Password not logged atau stored in plain text

3. **Data Validation**:
   - Server-side validation untuk all updates
   - SQL injection prevention
   - XSS protection untuk user inputs

### **File Upload Security**

1. **File Validation**:
   - File type verification (images only)
   - File size limits (max 5MB)
   - Malware scanning untuk uploaded files

2. **Storage Security**:
   - Secure file storage dengan access controls
   - CDN dengan proper caching headers
   - File access authentication
