## 🏗️ Template Structure

Setiap tiket folder akan berisi:

```
tickets/MXXXX-ticket-name/
├── README.md              # Detail tiket lengkap
├── user-story.md          # User story dan acceptance criteria
├── requirements.md        # Requirements detail
├── deliverables.md        # Daftar deliverables
└── references/           # Referensi dan resources
    ├── examples.md       # Contoh-contoh
    └── assets/          # Asset yang dibutuhkan
```

## 🔄 Workflow

1. **Tiket Creation** - Tiket dibuat dengan detail lengkap
2. **Assignment** - Tiket ditugaskan ke team member
3. **Implementation** - Team member mengerjakan tiket
4. **Review** - Hasil direview oleh team lead
5. **Approval** - Tiket disetujui dan ditandai selesai
6. **Documentation** - Hasil didokumentasikan di folder utama

## 📝 Guidelines for Ticket Creation

### Required Fields

- **Ticket ID**: MXXXX format
- **Title**: Deskripsi singkat dan jelas
- **Status**: Todo/In Progress/Done/Backlog
- **Priority**: High/Medium/Low
- **Estimation**: Dalam hari
- **Assignee**: Team atau individual
- **Description**: Detail lengkap kebutuhan

### Optional Fields

- **Dependencies**: Tiket lain yang diperlukan
- **Related Tickets**: Tiket terkait
- **Deadline**: Tanggal target selesai
- **Labels**: Kategori atau tags

## 📊 Metrics & Success Criteria

### Quality Metrics

- **Completion Rate**: Persentase tiket selesai tepat waktu
- **Review Score**: Rating dari reviewers (1-5)
- **Revisions**: Jumlah revisi yang diperlukan
- **User Feedback**: Feedback dari stakeholders

### Process Metrics

- **Cycle Time**: Waktu dari creation sampai completion
- **Throughput**: Jumlah tiket selesai per sprint
- **Backlog Size**: Jumlah tiket yang belum dimulai
- **Team Velocity**: Kapasitas tim per sprint

## 🚀 Getting Started

### Untuk Team Members

1. Pilih tiket dari backlog sesuai expertise
2. Update status menjadi "In Progress"
3. Kerjakan sesuai requirements
4. Submit untuk review
5. Address feedback jika ada
6. Update status menjadi "Done"

### Untuk Reviewers

1. Review deliverables sesuai acceptance criteria
2. Berikan feedback yang konstruktif
3. Approve jika memenuhi semua requirements
4. Request revisions jika diperlukan

### Untuk Team Lead

1. Assign tiket ke team members
2. Monitor progress secara berkala
3. Help remove blockers
4. Approve final deliverables
5. Update metrics dan reporting
